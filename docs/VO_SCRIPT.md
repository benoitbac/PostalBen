# PostalBen — Voice-over recording script

> Generated by `tools/Build-VoSheet.ps1`. Do not edit by hand —
> edit `game/localization/vo.csv` (text) or `tools/vo-directions.csv` (direction) and re-run.

## How to record

1. Record each line as its own take. One file per key.
2. Name the file exactly the key, `.wav`: `ben.wake.day1.wav`.
3. Drop files into `audio-raw/<locale>/` at the repo root (git-ignored — raw takes are big).
4. Run `pwsh tools/Normalize-Vo.ps1 -Locale <locale>` to convert, trim and level them into the game.
5. Leave 1s of silence at the head and tail of each take — the normalizer trims it and needs the room tone.

Mono, 48 kHz, 24-bit WAV. Pop filter. Same mic position for the whole session —
lines from different sessions sit next to each other in-game and tone shifts are audible.
